SQL is the language. MySQL is the engine that speaks it.

MySQL is one of the most widely used open-source relational database systems. It stores data in tables of rows and columns, and you ask it questions and make changes using SQL, the standard language for relational data.

Learn the fundamentals here and the skills carry over to PostgreSQL, SQL Server, Oracle and SQLite. The syntax differs in places, but the ideas stay the same.

Open source
MySQL Community Edition is free to download and use.
Reliable storage
The InnoDB engine provides transactions, row-level locking and crash recovery.
Proven at scale
It runs everything from personal projects to large production systems.
Works with your language
Connectors exist for Python, Java, PHP, Node.js, C# and many more.

Eight statements to know

Every example runs against the practice database. Copy one, paste it into the MySQL client, and change the values to see what happens.

Read rows

SELECT * returns every column. It is handy while exploring. In real work, name the columns you need.

SQL 
SELECT *
FROM students;

Filter rows

WHERE keeps only the rows that match a condition. Text values go in single quotes.

SQL 
SELECT first_name, last_name, city
FROM students
WHERE city = 'Kampala';

Sort and limit

ORDER BY sorts the result, and DESC reverses the order. LIMIT returns only the first rows.

SQL 
SELECT title, price
FROM courses
ORDER BY price DESC
LIMIT 3;

Add a row

INSERT names the columns first, then supplies the values in the same order.

SQL 
INSERT INTO students
    (first_name, last_name, email, city, birth_date, joined_on)
VALUES
    ('Ruth', 'Auma', 'ruth.auma@student.example', 'Kampala', '2003-02-14', CURDATE());

Change rows

UPDATE changes existing rows. Always include a WHERE clause, or every row in the table changes.

SQL 
UPDATE enrollments
SET grade = 81.00, status = 'completed'
WHERE enrollment_id = 2;

Remove rows

DELETE removes the matching rows. Run the same SELECT first to check exactly what will go.

SQL 
-- Preview the rows that will be removed
SELECT *
FROM enrollments
WHERE status = 'dropped';

-- Then delete them
DELETE FROM enrollments
WHERE status = 'dropped';

Combine tables

JOIN matches rows across tables using a shared key. Short aliases such as s and c keep the query readable.

SQL 
SELECT s.first_name, s.last_name, c.title, e.status
FROM enrollments AS e
JOIN students AS s ON s.student_id = e.student_id
JOIN courses  AS c ON c.course_id  = e.course_id
WHERE e.status = 'active';

Summarise groups

GROUP BY produces one row per group. WHERE filters rows before grouping, and HAVING filters the groups afterwards.

SQL 
SELECT c.category,
       COUNT(*)               AS total,
       ROUND(AVG(e.grade), 2) AS avg_grade
FROM enrollments AS e
JOIN courses AS c ON c.course_id = e.course_id
GROUP BY c.category
HAVING COUNT(*) >= 2
ORDER BY total DESC;

Practise on a real database

The practice database has four related tables, ten students, seven courses and eighteen enrollments. Setting it up takes about a minute.

  1. Download the script

    Save academy.sql in a folder you can reach from your terminal.

    Download academy.sql

  2. Run the script

    Load it with the MySQL client and enter your root password when prompted. The script drops and recreates academy_db, so never run it against data you need to keep.

    Terminal 
    mysql -u root -p < academy.sql

  3. Check the data

    Open the database with mysql -u root -p academy_db, then run this query. You should see 4, 10, 7 and 18 rows.

    SQL 
    SELECT 'instructors' AS table_name, COUNT(*) AS row_count FROM instructors
UNION ALL
SELECT 'students',    COUNT(*) FROM students
UNION ALL
SELECT 'courses',     COUNT(*) FROM courses
UNION ALL
SELECT 'enrollments', COUNT(*) FROM enrollments;

Common questions

Do I need programming experience?

No. The lessons start from first principles. Some later examples are easier if you have written code before, but nothing here requires it.

Is MySQL free?

Yes. MySQL Community Edition is free and open source. Oracle, which owns MySQL, also sells commercial editions with extra support and features.

What is the difference between SQL and MySQL?

SQL is the language used to work with relational databases. MySQL is a database system that understands SQL. PostgreSQL, SQL Server and other systems also use SQL.

Which version should I install?

MySQL 8.4 LTS is recommended. The practice script needs MySQL 8.0.16 or later.

Does this work on Windows, macOS and Linux?

Yes. MySQL has official installers for Windows and macOS, and most Linux distributions package it through their repositories or through MySQL's own package repository.
